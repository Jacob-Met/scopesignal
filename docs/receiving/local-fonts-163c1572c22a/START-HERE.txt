START THE APPLICATION

1. Extract the whole ZIP into a new folder. Keep app, evidence and the two
   start-scopesignal launchers together. The application needs an existing
   Node.js 24 or newer installation available as the command `node`.
   No npm install or downloaded font is needed to run this package.

2. Windows: double-click start-scopesignal.cmd.
   macOS/Linux: open a terminal and run:
       sh "/full/path/to/extracted-folder/start-scopesignal.sh"
   Replace the path with your extracted folder. Paths containing spaces work.

3. Open the loopback URL printed in that terminal, normally:
       http://127.0.0.1:4173
   Keep the terminal open while using the application. Press Ctrl+C there to
   stop the server. The page uses fonts already installed on your computer.

If `node` is not found, use a terminal where your existing Node.js installation
is available. If the terminal reports EADDRINUSE, the selected port is busy.
Leave that other program running and choose an unused positive port, for example:

   Windows PowerShell:
       $env:PORT = '4174'
       & 'C:\path\to\extracted-folder\start-scopesignal.cmd'

   macOS/Linux:
       PORT=4174 sh "/path/to/extracted-folder/start-scopesignal.sh"

Open the newly printed URL. This package preserves the selected source server:
use a positive integer port from 1 through 65535. Do not use PORT=0 with this
edition; its server would print zero instead of the actual allocated port.

USE THE EXISTING LOCAL TOOLS

The home page offers a fixture milestone with editable checkpoints and a local
rule preview. Approve an edited checkpoint, save its fixture record, and open
the saved-record viewer to choose that JSON file again. The recorded amounts
and history are simulated fixture data. This package makes no real payment.

Six existing pages are included. After the printed server address, use:

   /                    Fixture milestone and saved-record download
   /record.html         Open a saved fixture record
   /scope.html          Build a fixture scope
   /scope-compare.html  Compare saved scopes
   /scope-csv.html      Convert checkpoint CSV
   /scope-library.html  Saved workspace library

Use the application's save/export controls to keep records outside the browser.
Local saved files can be reopened with the corresponding page's file picker.
Retain exported files when moving the package to another folder or computer.
