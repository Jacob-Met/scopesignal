OPEN THE FOCUSED VIEWER
1. Extract this entire ZIP into a new directory.
2. With an existing Node 24 or later, open a terminal and run:
       node open-record.mjs
   From another working directory, pass the full quoted path to that file.
3. Open the printed http://127.0.0.1:PORT/record.html address in a browser.
4. Choose fixtures/mixed.json in the file picker to try the authored example,
   or choose an existing version 1 ScopeSignal fixed-fixture record.
5. Scroll to Raw recorded events. Choose a Checkpoint and an Event type.
   Both conditions must match. Show all events clears the filters.
6. Press Ctrl+C in the terminal to stop this companion when finished.

RECOGNIZE THE RESULT
The authored mixed record contains 13 interleaved recorded events across
three checkpoints. The full summary shows three approvals, $800.00 captured
and one pending checkpoint. Select First-run checklist: original sequences
1, 3, 5, 6, 8, 9 and 10 remain. Combine it with Webhook received: sequences 8
and 9 remain distinct, with false/true duplicate flags in their exact JSON.
Filtering retains each original row, sequence, ordering and open disclosure.
The summary and checkpoint outcomes always describe the complete admitted
record. A no-match selection does not mean the file has no captures.

A refused file selection retains the admitted record, current filters and
open disclosures. A valid replacement starts with all its own events.
Clear removes the display and retires any pending older read. Loading a
record does not restore an active payment workspace or save browser state.
