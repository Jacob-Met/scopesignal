## Reproduce

Use Node >=24 for the normal project gate:

```sh
npm test
```

With already installed Puppeteer and Chromium, run the maintained receiver from a checkout matching the source manifest. Choose a new private output directory. Snap Chromium on this host uses a profile/download directory under the user's home rather than a separate /tmp namespace.

```sh
SCOPESIGNAL_SOURCE=/absolute/exact-checkout \
SCOPESIGNAL_EVIDENCE=/absolute/new-output \
SCOPESIGNAL_SOURCE_MANIFEST=/absolute/candidate-r3-source-manifest.json \
SCOPESIGNAL_PUPPETEER=/absolute/installed/puppeteer \
SCOPESIGNAL_CHROME=/absolute/chromium \
node scripts/check-scope-checkpoint-csv.mjs
```

The record restoration guide below explains how to obtain the exact manifest and historical drivers. Archived Python `.py.txt` files are execution transcripts, not newly qualified Python modules. The current maintained receiver is the ordinary project `scripts/check-scope-checkpoint-csv.mjs`; it is not copied as a second maintained implementation.
